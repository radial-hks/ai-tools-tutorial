## 二、现有教程轨迹与能力空白

现有 4 期轨迹：

```
第1期 Copilot（写代码）→ 第2期 Skill（复用流程）→ 第3期 Hermes（执行任务）→ 第4期 Pi（多 Agent 协作）
```

台账记录暴露的能力空白：

```
现有：工具使用 → 流程复用 → 任务执行 → 多 Agent 协作
缺失：└─ 记忆层（Agent 怎么"记住"）┘
      └─ 代码理解层（Agent 怎么"读懂"仓库）┘
```

后续期次应顺着这个信号做专题，让教程从"工具介绍"升级为"Agent 工程能力建设"，与台账形成闭环。

## 五、与台账的闭环机制

1. 每期教程完成后，在台账对应条目的"备注"字段回写"已纳入第 N 期教程"。
2. 台账"状态"字段可从"已整理"升级为"已进入教程/已实测"。
3. 新调研项目按 `ai-knowledge-base-research` skill 归档，产生新记录后同步评估是否催生新期次。
