# Matt Pocock GitHub 工程技能生态 —— 团队参考手册

**受众：** 技术人员建议精读全文；无编程基础的美术、建模同事建议重点读第 1–2 章（了解"有什么"），第 3 章后半段（场景速查表），以及第 5 章（能不能用）。

**核验基线：** 内容按 GitHub 公开仓库核验于 2026-08。Matt Pocock 的仓库更新频率极高，发布前建议技术负责人确认关键仓库的最新 star 数和目录结构。

**一句话定位：** Matt Pocock 是全球最知名的 TypeScript 教育者之一（Total TypeScript 创始人），他在 GitHub 上开源了一套**面向真实工程的 Agent Skill 全集**（228k+ stars），覆盖 TDD、调试、代码审查、架构改进、原型设计等完整工程流程——这是目前全球最成熟、最实用的 AI 编程技能库，也是本期的核心讲解对象。

**标记约定：** 全手册沿用三个符号标注任务分工：

- 🤖 **AI 可替代**：让 Agent 帮你执行这一步。
- ⚠️ **必须由你决定**：账号、密钥、路径、最终效果、安全确认等，需要你亲自判断。
- 💡 **小提示**：补充说明、记忆口诀或可选做法。

- **只想了解「有什么、要不要用」**：读 [第 1 章](01-matt-pocock-and-ecosystem.md) + [第 5 章](05-team-adoption.md)，共约 12 分钟。
