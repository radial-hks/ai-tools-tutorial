# 工具协作与选型

## 本章解决什么

前面 6 期已经介绍了 6 个独立工具。本章把它们放在一起——六件套协作全景、选型决策表、以及学习路径建议。

## 六件套一句话复习

| 工具 | 一句话 | 第几期 |
| --- | --- | --- |
| **VS Code Copilot** | 编辑器里的 AI 结对编程，写代码最快 | 第 1 期 |
| **Copilot Skill** | 可复用的 AI 流程包，让 Copilot 遇到特定任务就自动加载 | 第 2 期 |
| **Hermes Agent** | 终端里的个人 AI 助理，适合长流程执行任务 | 第 3 期 |
| **Pi / OMP / herdr** | 终端里的极简 AI 编程助手 + 增强版 + 多面板工作区 | 第 4 期 |
| **Agent 记忆系统** | TencentDB / Mnemosyne / Hindsight 三选一，让 Agent 有长期记忆 | 第 5 期 |
| **DSH** | 可组合的 AI Agent 运行时框架，能力全可插拔 + 动态插件 | 第 6 期 |

## 六件套协作全景

```
                     ┌───────────────────────┐
                     │    Agent 记忆系统      │  ← 长期记忆层
                     │  (第 5 期)            │
                     └───────────┬───────────┘
                                 │ 给所有 Agent 提供记忆
        ┌────────────────────────┼────────────────────────┐
        │                        │                        │
   ┌────┴─────┐          ┌──────┴──────┐          ┌──────┴──────┐
   │ Copilot  │          │   Hermes    │          │ Pi / OMP    │
   │ + Skill  │          │   Agent     │          │ + herdr     │
   │ 写代码   │          │  执行任务   │          │ 多 Agent    │
   └──────────┘          └─────────────┘          └─────────────┘
   编辑器内              终端里                 终端里（多面板）
                                 │
                          ┌──────┴──────┐
                          │     DSH      │  ← 运行时框架
                          │  可组合·可扩展 │
                          └──────────────┘
                            Web GUI / TUI / Headless
```

- **Copilot** 管「写代码」——在编辑器里最顺手
- **Hermes** 管「执行长任务」——有记忆和技能，适合跨会话的复杂流程
- **Pi / OMP / herdr** 管「终端多 Agent 协作」——极简 + 多面板
- **DSH** 管「运行时定制」——当你想自己造 Agent、改 Agent 行为时
- **记忆系统**（可选）给所有这些 Agent 加一层长期记忆

## 选型决策表

按你「现在要做什么」来找对应工具：

| 你现在的任务 | 首选工具 | 备选 | 理由 |
| --- | --- | --- | --- |
| 写一段代码、改一个函数 | **Copilot** | Pi | 编辑器里的内联建议和聊天最快 |
| 执行一个多步骤的批量任务 | **Hermes** | DSH | Hermes 对长流程有更好的规划和状态追踪 |
| 在一个终端里同时盯多个 Agent | **Pi + herdr** | DSH（多会话） | herdr 的分栏体验专为此设计 |
| 创建一个可复用的 AI 工作流程 | **Copilot Skill** | Hermes Skill | 看团队主要在哪个平台工作 |
| 给 Agent 加长期记忆 | **记忆系统**（三选一） | — | 记忆层是独立基础设施 |
| 自定义 Agent 的工具和行为 | **DSH**（动态插件/Preset） | — | 只有 DSH 能在运行时改 Agent 配置 |
| 搭建 CI 或脚本化的 AI 任务 | **DSH**（headless） | Hermes CLI | DSH headless 模式专为脚本化设计 |
| 快速试一个想法、临时加个工具 | **DSH**（动态插件） | — | 定义→运行，不用改配置、不用重启 |

## 学习路径建议

### 路径 A：只想「用」AI，不想「造」AI

```
Copilot（第 1 期）→ Copilot Skill（第 2 期）→ Hermes / Pi（第 3-4 期）
```

学完这三步，你就有了三个互补的工具：编辑器里写代码 + 可复用的流程包 + 终端里执行任务。大部分日常 AI 需求都能覆盖。

### 路径 B：想深入定制 Agent 行为

```
Copilot（第 1 期）→ Pi（第 4 期）→ DSH（第 6 期）
```

先用 Copilot 和 Pi 感受不同 Agent 的设计理念，然后用 DSH 自己动手造。

### 路径 C：想搭建团队的 AI 基础设施

```
记忆系统（第 5 期）→ DSH（第 6 期）→ 自定义 Preset（第 6 期第 4 章）
```

先搞定「Agent 怎么记住东西」（记忆），再搞定「Agent 怎么按需组合」（DSH），最后把团队的最佳实践固化为自定义 Preset。

## DSH 与现有工具的协作示例

### 协作 1：用 DSH 写 Hermes Skill

```
Hermes 是你日常用的 AI 助理
  └─ 你发现某个流程需要一个新 Skill
       └─ 用 DSH（cordis 模式）让 AI 帮你起草 Skill 内容
            └─ 放到 Hermes 的 skills 目录
                 └─ Hermes 加载并使用
```

### 协作 2：用 DSH 分析 Pi 的会话记录

```
Pi 在 herdr 里跑一个长任务
  └─ 任务结束后，用 DSH 分析 Pi 的会话 JSONL
       └─ DSH 读取文件、提取关键信息、生成报告
            └─ 把报告交给 Copilot 做后续开发
```

### 协作 3：用 DSH 管理记忆系统

```
你在 DSH 里给 AI 交代一个任务
  └─ AI 需要记住上次的上下文
       └─ DSH 调用记忆系统（第 5 期）的 API
            └─ 存入/召回长期记忆
```

## 总结

| 维度 | 一句话 |
| --- | --- |
| **Copilot** | 编辑器里最快的 AI |
| **Copilot Skill** | 可复用的 AI 流程 |
| **Hermes** | 终端里的执行助理 |
| **Pi + OMP + herdr** | 终端里的多 Agent 工作台 |
| **记忆系统** | Agent 的长期记忆层 |
| **DSH** | 你自己造的 Agent 工作台 |

> 💡 不需要六件套全装——选对当前任务最适合的那一个就行。大部分情况下 Copilot + Pi 就够了。当你开始想「这个 AI 要是能多做一步就好了」，那就该看看 DSH 了。
