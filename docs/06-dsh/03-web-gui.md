# Web GUI 使用

## 本章解决什么

学会 DSH Web GUI 的日常操作：界面长什么样、怎么开会话聊天、有哪些快捷键、怎么管理文件和任务。

## 启动

```bash
dsh web
# 浏览器打开 http://127.0.0.1:3080
```

## 界面一眼看懂

Web GUI 是左右分栏布局：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 左侧会话列表 | 左栏 | 显示当前 Profile 下所有会话，可以新建、切换、搜索、删除 |
| 中间消息区 | 主区域 | AI 回复、工具调用与结果、文件预览、通知 |
| 底部输入框 | 主区域底部 | 打字的地方；支持多行、粘贴图片、`!` 快捷命令 |
| 右上设置 | 顶栏右侧 | 模型选择、Preset 切换、主题等 |

### 左侧会话列表

| 操作 | 怎么做 |
| --- | --- |
| 新建会话 | 点击「新建」按钮，或输入框打 `/new` |
| 切换会话 | 点击列表里的会话标题 |
| 搜索会话 | 列表顶部的搜索框 |
| 重命名会话 | 点击会话标题旁的编辑图标 |

> 💡 会话按项目（工作目录）自动分组，切换目录会自动过滤显示。

### 中间消息区

每条消息显示三块：

1. **用户消息**（你自己的话）+ 时间戳
2. **AI 回复**——Markdown 渲染，代码块有语法高亮和复制按钮
3. **工具调用卡片**（如果 AI 调用了工具）——显示工具名、输入参数、执行结果，可折叠

> 💡 AI 跑工具的时候，消息区会实时流式更新。如果任务太长，可以先干别的，回来再看结果。

### 底部输入框

输入框支持以下操作：

| 操作 | 怎么触发 |
| --- | --- |
| 发送消息 | `Enter` |
| 换行 | `Shift+Enter` |
| 粘贴图片 | `Ctrl+V`（截图、拖拽都行） |
| 引用文件 | 输入 `@` 弹出文件搜索，Tab 补全 |
| 运行终端命令并发送给 AI | 输入 `!命令`（如 `!ls -la`） |
| 只运行终端命令不发给 AI | 输入 `!!命令` |
| 切换思考强度 | 输入框左侧的强度选择器 |
| 停止 AI 回复 | 点击「停止」按钮 |

## 常用命令（`/` 开头）

在输入框里打 `/` 会弹出命令菜单。最常用的几个：

| 命令 | 作用 |
| --- | --- |
| `/new` | 开新会话 |
| `/model` | 切换模型 |
| `/preset` | 切换 Agent Preset（模式） |
| `/settings` | 打开设置面板 |
| `/goal` | 查看当前目标 |
| `/compact` | 手动压缩上下文 |
| `/help` | 查看帮助 |

## 会话管理进阶

### 会话上下文

DSH 的每次对话都保存在 `~/.dsh/sessions/` 下。会话上下文包括：

- 你和 AI 的对话历史
- AI 调用过的工具和结果
- 当前工作目录
- 激活的 Preset（模式）

> 💡 长会话会占用上下文窗口，DSH 会自动触发**压缩（compaction）**，把较早的对话总结为摘要。完整历史仍在会话文件里。

### 文件操作

AI 读写文件时需要沙箱策略批准。有三种策略级别（由管理员配置）：

| 策略 | 允许的操作 |
| --- | --- |
| `workspace-write` | 读写工作目录下的文件 |
| `danger-full-access` | 读写系统任意路径（需人工批准） |

> ⚠️ 本文档写作环境使用的是 `danger-full-access` 策略。团队使用时建议从 `workspace-write` 开始。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行 |
| `Ctrl+K` | 打开命令面板 |
| `Esc` | 取消 / 关闭弹窗 |

> 💡 Web GUI 的快捷键比终端工具少，大部分操作靠点击完成。如果你想要更丰富的键盘操作，试试 `dsh --profile tui`（需单独安装）。

## 查看会话信息

在输入框里输入 `/goal` 查看当前是否有进行中的目标；输入 `/settings` 可以调整：

- 会话标题生成方式
- 上下文压缩阈值
- UI 主题
