# 通用快捷键速查

> 跨工具共享的快捷键。以下是 VS Code 通用的基础快捷键（不含 Copilot 专用的）。

## VS Code 基础

### macOS

| 操作 | 快捷键 |
|------|--------|
| 命令面板 | `⇧⌘P` |
| 打开终端 | `⌃\`` |
| 文件搜索 | `⌘P` |
| 全局搜索 | `⇧⌘F` |
| 切换侧边栏 | `⌘B` |
| 切换面板 | `⌘J` |
| 关闭标签 | `⌘W` |
| 格式化文档 | `⇧⌥F` |

### Windows / Linux

| 操作 | 快捷键 |
|------|--------|
| 命令面板 | `Ctrl+Shift+P` |
| 打开终端 | `Ctrl+\`` |
| 文件搜索 | `Ctrl+P` |
| 全局搜索 | `Ctrl+Shift+F` |
| 切换侧边栏 | `Ctrl+B` |
| 切换面板 | `Ctrl+J` |
| 关闭标签 | `Ctrl+W` |
| 格式化文档 | `Shift+Alt+F` |
