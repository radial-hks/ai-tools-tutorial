# 上下文与提示工程

## 上下文管理：给 Copilot 正确的信息

**核心原则**：AI 的回答质量取决于你提供的信息质量。好的上下文 = 好的回答。

### 隐式上下文（自动提供）

VS Code 会自动将以下信息发送给 AI：
- 当前活动文件内容
- 当前选中的代码
- 当前文件名

### # 引用（明确指定上下文）

在聊天输入框中输入 `#`，可以引用各种上下文：

| 引用 | 作用 | 示例 |
|------|------|------|
| `#file` | 引用指定文件 | "解释 #utils.py 中的函数" |
| `#codebase` | 引用整个代码库 | "认证是怎么实现的 #codebase" |
| `#selection` | 引用当前选中内容 | "把 #selection 改成 TypeScript" |
| `#terminalSelection` | 引用终端选中内容 | "这个报错是什么意思 #terminalSelection" |
| `#changes` | 引用 Git 变更 | "给 #changes 生成发布说明" |
| `#problems` | 引用问题面板 | "修复 #problems 中的错误" |
| `#fetch` | 抓取网页内容 | "最新的 API 文档 #fetch https://..." |

**操作方式**：也可以直接拖拽文件/文件夹到聊天面板，或点击 "Add Context" 按钮选择。

### @ 引用（聊天参与者）

输入 `@` 调用特定的聊天助手：

- `@vscode` — 问 VS Code 使用问题（如 "@vscode 怎么开启自动换行"）
- `@terminal` — 问终端相关问题（如 "@terminal 列出 src 下最大的 5 个文件"）

### 图片作为上下文

- 可以把截图、设计图拖入聊天面板
- 例如：附上一张 UI 草图，让 Agent 按图实现
- 支持从浏览器拖拽图片

### 浏览器上下文

VS Code 内置浏览器，可以：
- 截取页面截图发给 AI
- 选中页面元素（含 HTML/CSS）发给 AI
- 把控制台日志发给 AI

### 会话管理

- **为不相关的任务开启新会话**：不要把不相关的问题堆在一个对话中，上下文污染会降低响应质量
- **删除不相关的历史**：删除不再相关的过去问答，或开始全新会话
- **压缩上下文**：使用 `/compact` 命令选择性压缩上下文，仅保留最相关的信息
- **分叉而非重新提示**：使用 `/fork` 探索替代方案而不丢失上下文

## 提示工程最佳实践

### 八大核心原则

#### 原则一：具体明确

**不要**：`让这个代码更好`

**要**：`给这个函数添加空值检查，如果参数为 null 返回空数组`

**不要**：`写一个搜索功能`

**要**：`写一个 TypeScript 函数，用二分查找在有序数组中搜索目标值。返回索引，找不到返回 -1。示例：binarySearch([1,3,5,7], 5) 返回 2`

#### 原则二：分解复杂任务

不要一次要求一整个功能，拆成小步骤：

1. `创建一个 Express.js REST API，包含用户和产品的端点`
2. `给两个端点添加输入验证和错误处理`
3. `现在添加验证逻辑的单元测试`

逐步迭代，每步都在上一步基础上完善。

#### 原则三：提供预期输出

告诉 AI 期望的输出格式、示例输入输出，让它能自验：

```
实现一个令牌桶限流器。写单元测试验证：
- 10 次/秒的请求允许通过
- 第 11 次请求被拒绝
- 等待 1 秒后令牌桶恢复
实现完成后运行测试。
```

> 官方文档称这是"你能做的最高杠杆的事情之一"。

#### 原则四：用上下文引用

- 用 `#file` 指定相关文件
- 用 `#codebase` 让 AI 搜索整个项目
- 用 `#selection` 聚焦到当前选中的代码

#### 原则五：迭代优化

第一轮结果不满意，不要从头开始。追问：
- `把错误处理改用 try/catch`
- `添加更多边界情况的测试`
- `把变量名改成更有意义的名称`

#### 原则六：让 AI 提出澄清问题

如果任务有歧义，指示 AI 在继续之前向你提问：

```
如果你对需求有任何不确定，先问我问题再开始实现
```

#### 原则七：并行任务

如果有多个独立任务，可以让 AI 并行执行以节省时间：

```
并行研究 X 和 Y，然后总结发现
```

#### 原则八：尽早纠偏

如果 AI 走向了错误方向，不要等它做完再纠正。在 AI 工作时发送消息：
- **Steer with Message（转向）**：让当前任务暂停，处理你的新消息
- **Add to Queue（排队）**：等当前响应完成后自动发送
- **Stop and Send（停止并发送）**：取消当前操作，直接发新消息

## 实用 Prompt 模板

**理解代码**：
```
解释 #codebase 中的认证机制是怎么工作的
```

**生成代码**：
```
创建一个 React 表单组件，使用 react-hook-form 管理表单状态，yup 做验证。包含姓名和邮箱字段。
```

**重构代码**：
```
把 #selection 中的回调函数改写为 async/await 风格，保持功能不变
```

**调试**：
```
为什么这个函数返回 undefined？#selection
```

**生成测试**：
```
给用户服务函数添加单元测试，覆盖正常输入、空输入、异常输入三种情况
```

**安全审查**：
```
对 REST API 做安全审查，检查认证授权、输入验证、速率限制。按优先级列出 TODO 清单。
```

**发布说明**：
```
根据 #changes 生成发布说明，按功能分类
```

## 非程序员（美术/建模）的 Prompt 建议

**场景：理解一个代码文件**
```
用简单的话解释 #file 这个文件是做什么的，不需要懂技术也能理解
```

**场景：让 AI 帮忙写脚本**
```
帮我写一个 Python 脚本，批量把文件夹里所有 .png 图片缩放到 512x512，保存到 output 文件夹
```

**场景：理解报错信息**
```
#terminalSelection 这个报错是什么意思？我该怎么解决？
```

**场景：从设计图生成代码**
```
[附上 UI 设计截图]
按照这张设计图，用 HTML 和 CSS 实现这个页面布局
```

**场景：用角色扮演获取专业建议**
```
你是一位技术美术（TA），请帮我理解 shader 的基本概念
```
