# Agent 模式：让 AI 自主完成多步任务

## 什么是 Agent 模式

Agent 是 VS Code 中的智能体，它可以：
- 自主规划任务步骤
- 读取和修改多个文件
- 运行终端命令
- 自我检查和纠错
- 直到任务完成

与普通 Chat 的区别：Chat 是你问一个问题、AI 回答一次；Agent 是你描述一个任务、AI 自主执行直到完成。

比喻：Chat 像你问同事一个问题，Agent 像你给实习生布置一个任务让他自己去搞定。

## 三种内置 Agent

| Agent | 用途 | 工具权限 |
|-------|------|---------|
| **Ask** | 提问、探索、理解代码 | 只读，不改代码 |
| **Agent** | 实现功能、修 bug、重构 | 完整编辑能力 |
| **Plan** | 生成实现计划 | 只读，做规划分析 |

## 如何使用

1. 打开 Chat 视图
2. 在输入框上方选择 Agent 类型（Ask / Agent / Plan）
3. 选择语言模型
4. 输入任务描述
5. 发送，Agent 开始自主工作

**示例**：
```
给网站头部添加深色模式切换按钮，确保在手机端也能正常显示
```

Agent 会自动：
- 分析当前项目结构
- 找到相关文件
- 修改头部组件
- 添加状态管理
- 测试效果
- 自我纠错

## 权限控制

Agent 有不同的权限级别，控制它的自主程度：

| 权限级别 | 说明 |
|---------|------|
| 全自动 | Agent 自行决定和执行 |
| 需要确认 | 每步操作都需你确认 |
| 只读 | 只能看不能改 |

建议新人在初期使用 "需要确认" 模式，熟悉后再逐步放开。

## Plan → 实现的工作流

这是 VS Code 官方推荐的最佳实践：先规划再实现。

1. 用 **Plan** Agent 生成实现计划：
   ```
   设计一个用户登录功能，包含邮箱密码登录和 OAuth 登录
   ```
2. 审查计划，追问修改
3. 切换到 **Agent** 执行计划
4. 审查改动

## 选择正确的 Agent 类型

| 场景 | 推荐 | 原因 |
|------|------|------|
| 理解代码 | Ask | 只读安全，不会误改 |
| 快速小修改 | Inline Chat | 不切面板，就地改 |
| 多文件功能开发 | Agent | 自主跨文件操作 |
| 复杂任务方案设计 | Plan | 先规划后执行，避免浪费 |
| 多任务并行 | 多个 Agent 会话 | 独立任务用独立会话 |

## Agent 类型（进阶）

除了内置的本地 Agent，还有：

- **Copilot CLI**：后台 Agent，任务足够清晰时交给它在后台跑
- **Cloud Agent**：云端运行，创建 PR，适合团队协作
- **第三方 Agent**：如 Anthropic、OpenAI 直连

可以在不同类型之间交接，对话历史会保留。
