# 最佳实践总结

## 项目配置最佳实践

1. **用 `/init` 开始**：输入 `/init` 让 AI 自动生成项目指令文件
2. **保持指令文件简洁**：指令在每次对话中都会加载，只放 AI 无法从代码推断的信息（非默认约定、架构决策、环境配置）
3. **用 applyTo 分隔规则**：不同文件类型用不同的 `.instructions.md`
4. **排除噪音文件**：配置 `search.exclude` 和 `files.exclude`，让搜索聚焦在源代码上
5. **限制工具数量**：只启用需要的工具，减少干扰、加快响应

## 日常使用最佳实践

1. **先 Plan 再 Implement**：复杂任务先用 Plan Agent 生成计划
2. **提供上下文**：用 `#file`、`#codebase` 给 AI 必要的背景
3. **分步迭代**：拆大任务为小步骤，逐步完善
4. **审查所有改动**：AI 生成的代码必须审查后再接受
5. **用内联聊天做小修改**：不用切到侧边栏，`⌘I` 就地改
6. **善用多会话**：可以并行运行多个会话处理不同任务

## 提示词最佳实践

1. **说清楚输入、输出和约束**
2. **给出示例**：输入什么，期望输出什么
3. **让 AI 自验**：提供测试用例和验收标准
4. **避免模糊**："让这个更好" → "减少时间复杂度" / "添加空值检查"
5. **迭代优化**：不满意就追问，不要从头开始
6. **让 AI 提问**：有歧义时让 AI 先问你
7. **尽早纠偏**：方向不对立即用 Steer/Stop

## 会话管理最佳实践

1. **不相关任务开新会话**：避免上下文污染
2. **删除过时历史**：或开始新对话
3. **用 `/compact` 压缩**：长对话压缩减少 token 消耗
4. **用 `/fork` 分叉**：探索替代方案不丢失上下文
5. **关闭不相关文件**：在 IDE 中只打开相关文件

## 模型选择建议

| 场景 | 推荐模型 |
|------|---------|
| 快速编辑、简单问题 | 快速模型（如 GPT-4.1） |
| 复杂重构、架构决策 | 推理模型（如 Claude Sonnet 4.6） |
| 不确定用哪个 | Auto（自动选择） |

- 更高的思考力度 = 更多 token = 更多的 AI 额度消耗
- 简单任务用快速模型，复杂任务才用推理模型
- 先规划再实现，避免在废弃代码上浪费额度

## 审查清单

AI 改完代码后，逐项检查：

- [ ] 是否实现了你要求的功能
- [ ] 边界情况是否处理（空值、异常输入）
- [ ] 是否有安全问题（注入缺陷、硬编码密钥、缺少输入验证）
- [ ] 代码可读性和可维护性
- [ ] 运行测试验证

## 常见问题与避坑

### Q: 补全建议不出现？
→ 检查：是否已登录 GitHub 账号 / 状态栏 Copilot 图标是否正常 / 文件类型是否被支持 / 网络是否正常

### Q: AI 生成的代码不符合项目规范？
→ 创建 `.github/copilot-instructions.md`，把你的规范写进去。用 `/init` 自动生成起点。

### Q: AI 回答偏离了意图？
→ 用 `Steer with Message` 在 AI 工作中发送纠正方向。或在 prompt 中更明确地描述约束。

### Q: 大型项目中 AI 响应很慢？
→ 1. 用 `#file` 精确指定相关文件，而不是 `#codebase` 全局搜索
   2. 配置 `search.exclude` 排除生成的文件和无关目录
   3. 减少启用的工具数量

### Q: 担心 AI 改坏代码？
→ 1. 使用 "需要确认" 权限级别
   2. 利用 diff 视图审查改动
   3. 重要改动前确保有 Git 提交
   4. 使用检查点回滚
   5. 用 PreToolUse Hook 阻止危险命令

### Q: Instructions 文件不生效？
→ 注意：自定义指令不影响内联补全建议（打字时的灰色提示），只影响 Chat 和 Agent 模式。

### Q: 如何优化 AI 信用额度消耗？
→ 1. 简单任务用快速模型，复杂任务才用推理模型
   2. 先规划再实现，避免在废弃代码上浪费额度
   3. 保持上下文精简
   4. 用 `/compact` 压缩长对话
   5. 为不相关任务开新会话

## 学习路径建议

### 第一阶段：入门（第 1 天）

- [ ] 安装 VS Code 和启用 Copilot
- [ ] 体验内联补全（打字时按 Tab 接受建议）
- [ ] 用 Chat 问一个关于代码的问题
- [ ] 用 Inline Chat 做一次代码修改

### 第二阶段：日常使用（第 1 周）

- [ ] 学会使用 `#file` 和 `#codebase` 引用上下文
- [ ] 学会用 Plan 模式规划任务
- [ ] 学会审查 AI 的改动并接受/撤销
- [ ] 创建项目的 `copilot-instructions.md`

### 第三阶段：进阶（第 2-4 周）

- [ ] 创建第一个 Prompt File（常用任务模板）
- [ ] 尝试 Agent 模式完成一个完整功能
- [ ] 了解 Custom Agent 概念
- [ ] 安装一个 MCP Server（如 Playwright）

### 第四阶段：定制（按需）

- [ ] 创建自定义 Agent
- [ ] 编写 Agent Skill
- [ ] 配置 Hooks 实现自动化
- [ ] 探索 Plugin 系统
