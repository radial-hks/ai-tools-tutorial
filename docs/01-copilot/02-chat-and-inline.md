# 基础使用

## 三种核心交互模式

### 1. Inline Suggestions（内联补全）—— 写代码时

**是什么**：当你在编辑器中输入代码时，Copilot 会在灰色虚文中显示补全建议。最轻量的交互方式，不打断编码节奏。

**怎么用**：
- 正常打字，建议自动出现
- 按 `Tab` 接受建议
- 按 `Esc` 拒绝建议
- 按 `Alt+]` / `Alt+[` 在多个建议间切换
- 部分接受：`Ctrl+→`（Mac: `Cmd+→`）逐词接受
- 如果建议不合适，继续打字即可忽略
- 悬停可查看其他备选建议

**示例**：输入 `def validate_email(` 后，Copilot 会自动建议函数体

### 2. Chat（聊天）—— 对话时

**是什么**：在侧边栏打开的聊天面板，用自然语言和 AI 对话。可以提问、让 AI 改代码、解释逻辑、探索代码库。

**怎么打开**：
- 点击标题栏的聊天图标
- 或按 `Ctrl+Alt+I`（Mac: `⌃⌘I`）
- 或运行命令 `Chat: Open Chat`

**两种聊天界面**：

| 界面 | 特点 | 适合场景 |
|------|------|---------|
| Chat View（聊天视图） | 在编辑器侧边栏，和你的代码工作区在一起 | 编码任务，紧贴代码 |
| Agents Window（智能体窗口） | 独立窗口，跨项目 | 高层任务，多项目并行编排 |

**基本用法**：
1. 在聊天输入框输入你的需求，如 "给登录表单添加输入验证"
2. 按 `Enter` 发送
3. AI 分析代码，做出修改，返回摘要
4. 继续追问进行迭代

**发送消息时的选项**（当 AI 正在工作时你可以打断）：

| 选项 | 作用 |
|------|------|
| Add to Queue（排队） | 等当前响应完成后自动发送 |
| Steer with Message（转向） | 让当前任务暂停，处理你的新消息 |
| Stop and Send（停止并发送） | 取消当前操作，直接发新消息 |

### 3. Inline Chat（内联聊天）—— 就地修改时

**是什么**：直接在编辑器代码中间弹出一个小的聊天框，不切换到侧边栏。适合针对当前选中的代码做快速修改。

**怎么用**：
1. 在编辑器中打开一个文件
2. 按 `Ctrl+I`（Mac: `⌘I`）
3. 在弹出的输入框输入你的需求
4. 选中代码块可以让修改更精确

**示例**：选中一个函数，按 `⌘I`，输入 "把这段代码改用 async/await"，Copilot 直接在原地展示 diff。用 Keep 或 Undo 接受/拒绝。

**终端内联聊天**：
- 在终端中按 `⌘I`（Mac）/ `Ctrl+I`（Win），可以问 shell 命令相关问题
- AI 生成命令后，`⌘Enter`（Mac）/ `Ctrl+Enter`（Win）运行
- 或 `⌥Enter`（Mac）/ `Alt+Enter`（Win）插入到终端再修改

### 4. Quick Chat（快速聊天）—— 临时提问

- 按 `Ctrl+Shift+Alt+L`（Mac: `⇧⌥⌘L`）打开轻量聊天面板
- 适合快速提问，不离开当前工作流

## 斜杠命令（Slash Commands）

在聊天输入框中输入 `/` 可以调用预设命令：

| 命令 | 作用 |
|------|------|
| `/explain` | 解释选中的代码 |
| `/fix` | 修复选中的代码错误 |
| `/tests` | 为选中的代码生成测试 |
| `/init` | 生成项目指令文件（详见 [05-进阶定制](05-advanced-customization.md)） |
| `/help` | 查看所有可用命令 |

## 检查点（Checkpoints）—— 安全回滚

- VS Code 在聊天交互的关键点自动创建文件快照
- 如果 AI 偏离方向，可以用检查点回滚到之前的状态
- 在源代码管理视图中暂存（Stage）更改会自动接受待pending编辑

## Smart Actions（智能操作）

VS Code 内置了一些一步式 AI 操作：
- **生成提交信息**：在源代码管理视图中点击按钮
- **修复错误**：在问题面板中点击修复建议
- **重命名符号**：自动生成重命名建议

## 审查 AI 的改动

AI 改完代码后，务必审查：

- **内联补全**：看灰色建议是否合理，Tab 接受
- **内联聊天**：展示 diff，用 Keep / Undo 按钮
- **Agent 多文件修改**：打开被修改的文件查看 inline diff，逐个 Keep 或 Undo
- **检查点回滚**：如果 agent 偏离方向，回退到已知良好状态而不是试图修复级联错误
- **安全问题**：检查注入缺陷、硬编码密钥、缺少输入验证。**不要在提示中粘贴凭据**
