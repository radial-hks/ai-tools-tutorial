# Pi 工作流团队参考手册

**受众:** 团队成员，尤其是无编程基础的美术、建模同事。

**核验基线:** 内容按本机实际环境核验于 2026-08（pi `0.84.1`、Oh My Pi `omp 17.2.15`、herdr `0.8.0`）。发布前建议技术负责人按团队实际账号、模型供应商和安装分发方式做最后确认。

**一句话定位:** Pi 是一套跑在终端里的极简 AI 编程助手。它把「和 AI 对话 + 让 AI 调用工具干活」这件事做得足够小、足够透明，同时可以随你的需要无限扩展；配合 Oh My Pi（功能更全的增强版）和 herdr（终端工作区管理器），可以在一个屏幕里并行推进多个任务。

**标记约定:** 全手册沿用两个符号标注任务分工：

- 🤖 **AI 可替代**：让 Pi / OMP 帮你解释、生成命令、排查错误、整理步骤。
- ⚠️ **必须由你决定**：账号、密钥、路径、最终效果、安全确认、是否覆盖文件等，需要你亲自判断。
- 💡 **小提示**：补充说明、记忆口诀或可选做法。

> ⚠️ **内部发布提示：** 本章命令均来自本机实测和官方文档；但团队可能使用统一模型账号、代理、镜像源或指定安装包。面向同事发布前，请把团队专属配置补充到 [第 2 章](02-installation.md)。

## 三大件一句话分工

| 工具 | 大白话 | 你能用它做什么 |
| --- | --- | --- |
| **Pi Agent**（`pi`） | 终端里的极简编程助手 | 读文件、改代码、跑命令，把「要动手」的活交给 AI 执行 |
| **Oh My Pi**（`omp`） | Pi 的功能加强版 | 在 Pi 基础上多了子代理、待办清单、浏览器、Python、LSP 等现成能力 |
| **herdr** | 终端工作区管理器 | 把多个终端分栏排布，一眼看到「另一个面板在跑什么」，还能派活给旁边的 agent |

## 阅读建议

- **只想装好能用**：读 [第 2 章](02-installation.md)，把命令发给 Pi 或 Copilot，让它边解释边带你装。
- **先搞清楚「为什么又是新工具」**：读 [第 1 章](01-why-pi.md)。
- **已经装好了、想学会日常使用**：从 [第 3 章](03-pi-agent.md) 开始。
- **想知道 Oh My Pi 和 herdr 到底干嘛的**：读 [第 4 章](04-oh-my-pi.md) 和 [第 5 章](05-herdr.md)。
- **不确定该用 Copilot / Hermes / Pi 中的哪一个**：读 [第 6 章](06-cooperation.md) 的选型表。
