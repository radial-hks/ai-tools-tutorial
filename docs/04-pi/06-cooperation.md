# 三者配合与选型

## 本章解决什么

把这一期和前面几期串起来：Copilot、Hermes、Pi、Oh My Pi、herdr 到底各管什么、怎么配合，以及面对一个具体任务时该选谁。读完你能给团队同事一个清晰的「选型地图」。

## 一张全景图

```text
                    ┌────────────────────────────────────────────┐
                    │              herdr（窗口调度员）             │
                    │   一个屏幕并行多个 pane，查看/派发/等待        │
                    └───────┬────────────────────┬───────────────┘
                            │ pane A             │ pane B
                    ┌───────▼───────┐    ┌───────▼───────┐
                    │  pi / omp     │    │  pi / omp     │
                    │ （终端施工队）  │    │ （终端施工队）  │
                    └───────────────┘    └───────────────┘

  编辑器内：Copilot（顾问，陪你写）      个人执行助理：Hermes（长期记忆 + 流程复用）
```

- **Copilot** 活在编辑器里，负责「边写边问」。
- **Hermes** 是个人执行助理，强在 Memory / Skill / 长期流程。
- **Pi / OMP** 活在终端里，负责「把活干完」，透明、可改、可扩展。
- **herdr** 是调度层，把多个 Pi / OMP（甚至其他 agent）排进一个屏幕。

## 三者（本期三大件）怎么配合

| 环节 | 谁来做 |
| --- | --- |
| 想清楚要干什么、验收标准 | ⚠️ 你 |
| 在编辑器里改代码、写文档草稿 | Copilot |
| 在终端里批量读文件、跑命令、改文件 | Pi（轻活）或 OMP（重活） |
| 同时推进两个互不干扰的任务 | herdr 左右分栏，各跑一个 agent |
| 看「隔壁 agent 干到哪了」 | `herdr pane read` |
| 需要长期记住偏好、复用流程 | Hermes 的 Memory / Skill |

> 💡 典型协作流：**在 herdr 里开两个面板，左边 Pi 干 A 任务、右边 OMP 干 B 任务；你在编辑器里用 Copilot 复核产出；Hermes 负责记住「以后输出统一放哪」这类长期约定。**

## 选型地图

| 你的情况 | 建议 |
| --- | --- |
| 主要写代码、边写边问、改完即用 | **Copilot** |
| 需要长期记忆、可复用的执行流程、跨会话协作 | **Hermes** |
| 想在终端里透明地读文件、跑命令、改代码，且要极简可控 | **Pi** |
| 想要开箱即用的子代理、待办、LSP、浏览器、Python 等 | **Oh My Pi（OMP）** |
| 想一个屏幕并行多个 agent、查看彼此状态 | **herdr**（配合 Pi / OMP 使用） |

一句话速记：

| 口诀 | 含义 |
| --- | --- |
| 陪写找 Copilot | 编辑器内的顾问 |
| 长流程找 Hermes | 记忆 + 技能的执行助理 |
| 轻活找 Pi | 极简终端施工队 |
| 重活找 OMP | 全装版终端施工队 |
| 多开找 herdr | 管窗口、看隔壁的调度员 |

## 推荐学习路径

1. **第 1 步**：装 Pi（[第 2 章](02-installation.md)），跑通 `pi -p "你好"`。
2. **第 2 步**：日常轻活用 Pi（[第 3 章](03-pi-agent.md)），熟悉 `/` 命令和 AGENTS.md。
3. **第 3 步**：需要更全能力时用 OMP（[第 4 章](04-oh-my-pi.md)）。
4. **第 4 步**：用 herdr 开两个面板，体验并行（[第 5 章](05-herdr.md)）。
5. **第 5 步**：把前面学过的 Copilot、Hermes 按本节选型地图组合使用。

> ⚠️ 无论用哪个工具，共同的安全底线不变：**API 密钥和密码不交给任何 AI 保管；覆盖、删除、批量修改正式文件前由你确认；AI 的输出最终由你验收。**
