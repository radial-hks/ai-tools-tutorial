# 为什么需要 Pi

## 本章解决什么

团队已经写了 Copilot（第 1 期）和 Hermes（第 3 期），为什么还要再学一个 Pi？本章用最通俗的话讲清楚：Pi 补的是哪一块空缺、它和前面两个工具的区别、以及本期的「三大件」各自负责什么。读完你可以判断自己是否需要它。

## 一句话说清楚

**Pi 是跑在终端里的极简 AI 编程助手。**

它的核心就一句话：**你给目标，它在终端里帮你读文件、改代码、跑命令，一步步把活干完。** 它没有花哨的界面，所有动作都摊开在终端里，看得见、可回退。

> 把它和前面两期对比，会更容易理解：
>
> - **Copilot** 是「编辑器里的顾问」：你在 VS Code 里写代码，它陪你写、帮你改、给你建议。
> - **Hermes** 是「个人执行助理」：强调 Memory、Skill、跨会话的长期记忆和流程复用。
> - **Pi** 是「终端里的施工队」：极简、透明、可无限扩展，特别适合「我就要它在终端里把这件事做完」的场景。

## 为什么有了 Copilot 和 Hermes 还需要 Pi

| 需求 | Copilot | Hermes | Pi |
| --- | --- | --- | --- |
| 在编辑器里边写边问 | ✅ 最擅长 | 一般 | 一般（不在编辑器里） |
| 长期记忆、复用流程 | 一般 | ✅ 擅长 | 可扩展，但默认极简 |
| 在终端里直接读文件、跑命令、改代码 | 受限（在 IDE 内） | ✅ | ✅ 最纯粹 |
| 想要一个「随我改造」的最小工具 | 不可 | 不可 | ✅ 核心卖点 |
| 一个屏幕并行开多个 agent | 一般 | 需配合 | ✅ 配合 herdr |

Pi 的价值不在「功能最多」，而在**足够小、足够透明、足够可改**：

1. **透明**：它做的每一步（读了哪个文件、跑了哪条命令、改了什么）都实时打印在终端里，不像黑盒。
2. **可回退**：改动配合 Git，随时可以撤销；会话按文件保存，随时可以回到之前的某个节点继续。
3. **可扩展**：Pi 本身只带最基础的四个工具（读、写、改、跑命令），但你可以用**技能（Skill）**、**扩展（Extension）**、**主题**和 **Pi 包（Pi Package）** 把它改造成任何你想要的样子。
4. **多模式**：既能交互式聊天，也能一条命令出结果（`pi -p`）、给程序调用（JSON / RPC / SDK）。

> 💡 一句话记住：**Copilot 陪你在编辑器里写，Hermes 帮你做长期执行助理，Pi 给你一个在终端里「看得见、改得动、装得轻」的施工工具。**

## 本期的三大件：Pi Agent、Oh My Pi、herdr

本期不是只讲 Pi 一个工具，而是讲「一套终端工作流」，它由三件东西组成：

| 工具 | 是什么 | 角色类比 |
| --- | --- | --- |
| **Pi Agent**（`pi`） | 极简终端编程助手，本期的主角 | 基础施工队：人少、透明、听指挥 |
| **Oh My Pi**（`omp`） | Pi 的「功能加强版」，默认带更多现成能力 | 全装施工队：自带子代理、待办清单、浏览器、Python 等 |
| **herdr** | 终端工作区管理器，把多个终端分栏排布、识别其中的 agent | 工地调度员：一个屏幕管多个施工队，能「看到隔壁在干嘛」 |

三者的关系可以这样理解：

- **Pi** 是地基和标准：它定义了「在终端里和 AI 协作」这件事的最小做法。
- **Oh My Pi** 站在 Pi 的地基上，把很多常用能力（子代理、待办、LSP、浏览器等）预先装好了，省得你自己搭。
- **herdr** 管的是「屏幕和终端」这一层：它不在乎里面跑的是 Pi 还是 Oh My Pi，它负责把多个终端排列成工作区（workspace）、标签页（tab）、面板（pane），让你**一个屏幕同时看到多个 agent 在做什么**。

> 💡 这三个名字容易混，记住一句口诀：**Pi 和 Oh My Pi 是「干活的 agent」，herdr 是「管窗口的调度员」。**

## 适合先从哪些任务开始

和 Hermes 一样，建议从低风险任务练手：

1. 让 Pi 读取一个测试目录，列出文件清单。
2. 让 Pi 生成一份 Markdown 报告，不修改原文件。
3. 在复制出来的测试文件夹里尝试批量重命名或格式转换。
4. 用 herdr 在旁边再开一个面板，体验「一个屏幕两个 agent」。
5. 确认结果正确后，再迁移到正式项目。

> ⚠️ 不建议第一次就让 Pi 对正式素材目录做「删除、覆盖、批量移动」等操作；也不要把 API 密钥、密码交给它保管。
