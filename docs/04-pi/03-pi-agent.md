# 使用 Pi Agent

## 本章解决什么

装好 Pi 之后，学会日常怎么用：怎么启动、界面长什么样、常用命令和快捷键、会话怎么管理、以及怎么给项目写「使用说明」（AGENTS.md）。

## 启动 Pi

| 场景 | 命令 | 说明 |
| --- | --- | --- |
| 交互式聊天 | `pi` | 进入界面，边聊边干 |
| 带着任务启动 | `pi "列出 src/ 下的文件"` | 一句话交代任务 |
| 一条命令出结果 | `pi -p "总结这个仓库"` | 跑完直接退出，适合脚本化 |
| 引用文件 | `pi @prompt.md "回答这个"` | `@` 加文件名，把文件内容一起发给 Pi |
| 继续上次会话 | `pi -c` | 接着最近一次继续聊 |
| 挑选历史会话 | `pi -r` | 从列表里选一个恢复 |

> 💡 `@文件` 在交互界面里也能用：输入框里打 `@` 会弹出文件模糊搜索，Tab 键补全路径。

## 界面一眼看懂

交互界面从上到下四块：

| 区域 | 作用 |
| --- | --- |
| 顶部启动头 | 显示快捷键入口、已加载的 AGENTS.md、技能、扩展等 |
| 中间消息区 | 你的消息、AI 回复、工具调用与结果、通知、扩展 UI |
| 底部输入框 | 打字的地方；边框颜色表示当前思考强度 |
| 底部状态栏 | 工作目录、会话名、token/缓存用量、花费、上下文占用、当前模型 |

在输入框里可以：

- `Shift+Enter`（Windows Terminal 用 `Ctrl+Enter`）换行。
- `Ctrl+G` 打开外部编辑器写长内容。
- `Ctrl+V` 粘贴图片或文本（可把截图拖进去让 Pi 看图）。
- `!命令` 直接跑一条终端命令并把输出发给 Pi；`!!命令` 只跑不发给 Pi。

## 常用命令（`/` 开头）

在输入框里打 `/` 会弹出命令。最常用的几个：

| 命令 | 作用 |
| --- | --- |
| `/login` / `/logout` | 管理模型登录凭证 |
| `/model` | 切换模型 |
| `/settings` | 思考强度、主题、消息投递、传输方式 |
| `/new` | 开新会话 |
| `/resume` | 从历史会话里挑一个继续 |
| `/name <名字>` | 给当前会话起个名字 |
| `/session` | 查看会话信息（文件、ID、消息数、token、花费） |
| `/tree` | 打开会话树，跳回任意历史节点继续 |
| `/compact [提示]` | 手动压缩上下文（太长的会话会撑爆上下文窗口） |
| `/export [文件]` | 把会话导出成 HTML 或 JSONL |
| `/share` | 上传为私有 GitHub gist，生成可分享链接 |
| `/reload` | 重新加载快捷键、扩展、技能、主题、上下文文件 |
| `/hotkeys` | 查看全部快捷键 |
| `/quit` | 退出 Pi |

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+C`（一次） | 清空输入框 |
| `Ctrl+C`（两次） | 退出 Pi |
| `Esc` | 取消 / 中断当前任务 |
| `Esc`（两次） | 打开会话树 `/tree` |
| `Ctrl+L` | 打开模型选择器 |
| `Ctrl+P` / `Shift+Ctrl+P` | 在已勾选的模型之间前后切换 |
| `Shift+Tab` | 切换思考强度 |
| `Ctrl+O` | 折叠/展开工具输出 |
| `Ctrl+X` | 复制最后一条 AI 回复 |

> 💡 全部快捷键用 `/hotkeys` 查看，也可以在 `~/.pi/agent/keybindings.json` 自定义。

## 会话（Session）

Pi 的会话自动保存为会话记录文件，按工作目录组织，默认在 `~/.pi/agent/sessions/` 下。会话是「树结构」：你可以随时回到历史上的某个节点，换一种做法继续，所有历史都保留在一个文件里。

| 能力 | 说明 |
| --- | --- |
| `/tree` | 原地浏览会话树，跳到任意节点继续 |
| `/fork` | 从某条历史用户消息新建一个会话文件 |
| `/clone` | 复制当前分支，开一个全新会话 |
| `pi --fork <id>` | 从命令行直接分叉某个历史会话 |

> 💡 长会话会占用上下文窗口，Pi 默认会自动「压缩」（summarize）较早的消息，压缩是有损的；完整历史仍在会话记录文件里，可用 `/tree` 回看。

## 给项目写「使用说明」：AGENTS.md

Pi 每次启动时会自动读取上下文文件 `AGENTS.md`（或 `CLAUDE.md`），位置依次是：

1. 全局 `~/.pi/agent/AGENTS.md`
2. 从当前目录向上逐级父目录里的 `AGENTS.md`
3. 当前目录的 `AGENTS.md`

你可以在项目的 `AGENTS.md` 里写「项目约定、常用命令、注意事项」，Pi 就会自动遵守。改完记得 `/reload` 或重启生效。

> 💡 本仓库根目录的 `AGENTS.md` 就是一个例子：里面记录了「查看其他面板一律用 herdr」这类项目专属约定。

## 定制：让 Pi 变成你想要的样子

Pi 默认极简，但可以按需扩展（第 1 章提过「可扩展」是它的核心卖点）：

| 手段 | 是什么 | 放哪里 |
| --- | --- | --- |
| **技能 Skill** | 按需加载的能力包，按触发条件自动启用 | `~/.pi/agent/skills/`、`.pi/skills/`、`.agents/skills/` |
| **扩展 Extension** | TypeScript 写的自定义工具、命令、快捷键、UI | `~/.pi/agent/extensions/`、`.pi/extensions/` |
| **主题 Theme** | 改配色，热重载即时生效 | `~/.pi/agent/themes/`、`.pi/themes/` |
| **Pi 包 Package** | 把上面这些打包分发（npm / git） | `pi install npm:xxx` / `pi install git:xxx` |

> ⚠️ 第三方 Pi 包和扩展运行在你的电脑上，拥有完整系统权限；安装前先看源码。团队内以技术负责人审核过的清单为准。
